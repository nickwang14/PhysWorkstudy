# Curriculum Backlog

This file tracks curriculum ideas that are intentionally deferred so the current learning path stays focused and coherent.

## Purpose
Use this backlog when:
- a topic is valid but too advanced for the current chapter
- a concept belongs in a later gate rather than the active one
- we want to preserve future content ideas without expanding scope immediately
- the topic was surfaced during lesson drafting or textbook comparison but should not be included in the current foundations flow

## Lesson-Planning Triage Rule
When drafting a lesson:
1. Place the concept in its active chapter and subchapter.
2. Expand enough detail to teach the principle clearly.
3. Compare the lesson against the source textbook or chapter reference.
4. If the topic is still valid but beyond the current stage, move it to this backlog.
5. Keep the active lesson set focused on the learner's next unlockable concept.

## Deferred for Later Chapters

### Advanced mechanics
- Detailed force vectors
- Torque calculations
- Static and dynamic equilibrium in formal mechanics terms
- Advanced lever analysis and moment arms
- More quantitative joint mechanics

### Pathology and rehab-specific content
- Condition-specific pathology overviews
- Rehab protocol style progressions
- Clinical assessment frameworks
- Detailed tissue injury classification
- Medical red-flag or diagnosis-adjacent content beyond non-clinical boundaries

## Future Chapter Enrichment Candidates

### Chapter 3 and beyond
- Additional kinematics problem sets
- Additional work and energy coaching examples
- Additional momentum and impulse review cases

## Backlog Rules
- Do not pull items into active chapter work without checking MVP and curriculum fit first.
- Prefer adding depth only when it improves learner understanding, not just academic completeness.
- If a topic changes product scope or safety boundaries, update product decisions or risk docs before writing lessons.

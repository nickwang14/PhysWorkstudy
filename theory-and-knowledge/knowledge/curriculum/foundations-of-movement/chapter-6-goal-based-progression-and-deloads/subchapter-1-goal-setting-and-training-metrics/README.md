# Goal-Setting and Training Metrics

## Overview
Progress is easier to manage when the goal is clear. Training metrics give structure without turning the user into a performance machine.

## Key Ideas
- goals should be clear, realistic, and tied to user needs
- metrics can include frequency, session completion, movement quality, or effort trend
- not all progress is visible in a single number
- a useful metric supports decision-making instead of creating anxiety

## Connection to Practice
This subchapter connects the app's progression logic to the user’s actual life and training goals. It supports a long-term, research-informed view of growth.

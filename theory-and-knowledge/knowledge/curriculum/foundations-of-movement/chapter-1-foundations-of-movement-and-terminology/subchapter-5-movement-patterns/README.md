# Movement Patterns

## Overview
Movement patterns are repeatable ways the body moves to produce or control force. They help us organize exercise selection and learning around function rather than sheer variety.

## Key Patterns
- squat pattern
- hinge pattern
- push pattern
- pull pattern
- carry pattern
- rotate / anti-rotation pattern

## Why It Matters
Understanding patterns helps learners connect exercises across many movement contexts. A single pattern can appear in many different exercises, making it easier to reason about exercise selection and progression.

## Connection to Practice
A strong program should include foundational movement patterns in a balanced way. It should also teach the user that exercise novelty is not the same as training quality.

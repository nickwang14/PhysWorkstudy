# Regression, Progression, and Load Adjustment

## Overview
Coaching is often about deciding what to change next. A learner should know how to reduce complexity, hold a plan steady, or increase challenge in a thoughtful way.

## Key Ideas
- regression is a useful tool, not failure
- progression should happen with purpose and evidence from the current plan
- load should usually change one variable at a time when possible
- plan coherence matters more than a dramatic change in effort

## Connection to Practice
This subchapter helps the learner understand how real users and coaches make adjustments without turning the plan into random experimentation.

## Knowledge Check
When should a coach reduce exercise complexity instead of adding more load?

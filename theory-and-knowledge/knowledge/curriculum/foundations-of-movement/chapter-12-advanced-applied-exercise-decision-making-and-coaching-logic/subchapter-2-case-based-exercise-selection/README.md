# Case-Based Exercise Selection

## Overview
This lesson uses cases to decide which exercise fits best. The learner should practice choosing based on goal, constraint, and movement quality rather than preference alone.

## Key Ideas
- case-based selection is context-sensitive
- exercise choice should match the reason the movement is needed
- different users may need different versions of the same pattern
- selection is a reasoning skill, not a memorization task

## Connection to Practice
The learner should be able to explain why one variation is more suitable than another in a given case.

## Scenario
A learner works through a case involving subchapter 2 case based exercise selection. They should explain what changes, why it matters, and what the next training decision should be.

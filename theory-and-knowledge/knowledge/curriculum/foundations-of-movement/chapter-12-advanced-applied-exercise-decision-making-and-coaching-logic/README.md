# Chapter 12: Advanced Applied Exercise Decision-Making and Coaching Logic

## Chapter Purpose
This chapter synthesizes the whole curriculum into advanced coaching decisions. It focuses on case-based reasoning, communication, and program synthesis under realistic constraints.

## Learning Outcomes
By the end of this chapter, the learner should be able to:
- apply decision trees to exercise and program changes
- explain coaching decisions clearly to a user
- compare multiple program responses to the same constraint
- reason through a case without drifting into clinical territory
- synthesize consistency-first programming logic

## Subchapters
1. Decision trees for programming changes
2. Case-based exercise selection
3. Coaching language and trust
4. Constraint-led case reasoning
5. Consistency-first synthesis

## Primary References
- Applied coaching texts
- Exercise science frameworks

## Unlock Rule
This chapter unlocks when the learner can justify a program change and explain it in clear, non-clinical language.

## Scenario
A learner works through a case involving chapter 12 advanced applied exercise decision making and coaching logic. They should explain what changes, why it matters, and what the next training decision should be.

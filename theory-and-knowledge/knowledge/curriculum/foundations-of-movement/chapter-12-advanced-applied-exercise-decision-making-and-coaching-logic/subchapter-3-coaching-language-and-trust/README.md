# Coaching Language and Trust

## Overview
How the app explains a plan matters. Coaching language should be calm, clear, and educational so the user trusts the system and understands why decisions are made.

## Key Ideas
- language should reduce confusion
- explanations should connect actions to goals
- trust improves when the user understands the reason for a change
- good coaching avoids hype and guilt

## Connection to Practice
This lesson supports the app's educational, academic tone.

## Knowledge Check
How does clear coaching language affect user trust and adherence?

## Scenario
A learner works through a case involving subchapter 3 coaching language and trust. They should explain what changes, why it matters, and what the next training decision should be.

# Training Planning Guide

## Overview
This guide introduces the early logic behind a flexible weekly training plan.

## Planning Principles
1. Start with the user's target workout frequency
2. Set a minimum threshold that is realistic and sustainable
3. Build in recovery and deload weeks
4. Adjust the next week based on actual logged progress, not just intention
5. Keep programming explainable and structured

## Example
A user sets a goal of 3 workouts per week. If they complete only 2, the following week should not be treated as failure. The system can adapt by reducing total volume, increasing mobility or recovery support, or suggesting a more realistic split.

## Key Rule
The system should prefer consistency and explainability over all-or-nothing pressure.
